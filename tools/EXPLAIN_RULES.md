# 기출 회차 해설 작성 규칙

대상: `data/imported-sets.json` 중 지시받은 회차. 각 문항의 `explanation` 은 현재 자리 표시 문구뿐이다. 해설을 새로 쓴다.

## 쓰는 것 (문항마다)
- `explanation`: 해설. 3~6문장, 한국어 평서문(「~이다」). 아래를 담는다.
  - 왜 그 답인지: 핵심 개념·정의를 자기 말로.
  - 헷갈리는 비슷한 용어와 어떻게 구분하는지.
  - 계산 문제는 풀이 과정을 단계별로.
  - 코드 문제는 핵심 변수의 값 변화를 따라가며 최종 출력이 나오는 과정을 요약(반복 회차별 값, 호출 순서 등). 표가 필요하면 `|` 마크다운 표 대신 문장·짧은 나열로 쓴다.
  - 서술형(「설명하시오」)은 모범답안의 핵심어(채점 포인트)를 짚는다.
- `point`: 출제 포인트. 10~25자의 짧은 주제명(예: 「C 버블 정렬 결과」, 「DoS 공격 유형」).
- `area`: 영역 하나. 다음 중에서만 고른다: `C 언어`, `Java`, `Python`, `SQL`, `소프트웨어 설계`, `데이터베이스`, `네트워크`, `운영체제`, `정보 보안`, `테스트`, `통합·패키징`, `요구사항·기타`.
- `answerCheck`: `ok` 또는 `suspect`. 저장된 정답(`parts[].answers[0]`)이 맞는지 확인한 결과.
- `answerNote`: suspect 일 때만. 무엇이 의심되는지와 올바르다고 보는 답, 근거. 저장된 정답은 **바꾸지 않는다**. 해설은 올바르다고 판단한 내용으로 쓰되, 저장된 답과 다르면 그 점을 해설 끝에 한 문장으로 밝힌다.

## 지킬 것
- 해설은 직접 새로 쓴다. 웹 검색·WebFetch 를 쓰지 말고, 다른 사이트나 책의 해설 문장을 옮기지 않는다.
- 「위키해설」 같은 출처 문구를 쓰지 않는다.
- 문항에 `images` 가 있으면 `data/imported-images/` 의 해당 PNG 를 Read 로 직접 보고 해설한다.
- 코드 문항은 반드시 직접 확인한다. 작업 폴더: `C:\Users\clush\AppData\Local\Temp\claude\C--workspace\0aa2bfa3-db55-4e0a-ab12-2b2fd40093c1\scratchpad\expl\<회차키>\`.
  - Java: `Main.java` 로 저장(클래스 이름이 다르면 맞게 바꿔서) → `javac Main.java && java -cp . Main`. CLASSPATH 환경변수 때문에 `-cp .` 가 필요하다.
  - C: 컴파일러가 없다. 손 추적 후 Node(JavaScript) 또는 Java 로 의미 그대로 이식해 실행해 교차 확인(int 32비트, 정수 나눗셈 절삭, 포인터 → 인덱스, printf 포맷).
  - Python: 인터프리터가 없다. 손 추적 후 Node 로 이식해 교차 확인(슬라이싱, // 와 % 의 음수 규칙, 리스트·딕셔너리 출력 형식).
  - Bash 는 Git Bash 다. 한글 인자를 curl 등에 넘기지 않는다.
- 기출 복원 문제라 원문에 오타나 빠진 부분(헤더 이름, 괄호)이 있을 수 있다. 의도가 분명하면 의도대로 풀고 해설에 짧게 언급한다.
- 저장소의 다른 파일은 수정하지 않는다. 결과 파일만 쓴다.

## 출력
`C:\workspace\ipe-silgi\data\explanations\<회차키>.json` 에 UTF-8(BOM 없음)로 저장. 회차키는 `past-2020-1` 처럼 set 의 `key` 그대로.

```json
{
  "past-2020-1-1": { "explanation": "…", "point": "…", "area": "통합·패키징", "answerCheck": "ok" },
  "past-2020-1-17": { "explanation": "…", "point": "…", "area": "C 언어", "answerCheck": "suspect", "answerNote": "…" }
}
```

해당 회차의 **모든 문항 id** 를 빠짐없이 넣는다. 저장 후 Node 로 JSON 파싱과 id 누락 여부를 확인한다.
최종 답변은 저장 경로, 문항 수, suspect 목록(id + 한 줄 사유)만.
